# SENTINEL

SENTINEL is a React, TypeScript, and Vite app for exploring text sentiment and language signals in social media posts. A successful text analysis is generated by Gemini and saved with the submitted text in browser-local history for the signed-in account. It is not a diagnosis or evidence of a person's mental state.

## Environment variables

Set these values in an ignored local `.env.local` file for `vercel dev`, and in the Vercel project's Environment Variables before deployment:

| Variable | Where it is used | Required |
| --- | --- | --- |
| `VITE_SUPABASE_URL` | Frontend and API token verification | Yes |
| `VITE_SUPABASE_ANON_KEY` | Frontend and API token verification; use only the browser-safe anon key | One of these two keys |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Alternative browser-safe project key | One of these two keys |
| `SENTINEL_DEMO_USERNAME` | Server-side Demo Access sign-in | Yes for Demo Access |
| `SENTINEL_DEMO_PASSWORD` | Server-side Demo Access sign-in; never sent to Vite/browser code | Yes for Demo Access |
| `SENTINEL_DEMO_SIGNING_SECRET` | Server-side signing of short-lived Demo Access cookies; at least 32 characters | Yes for Demo Access |
| `GEMINI_API_KEY` | Server-side `/api/analyze` function only | Yes for analysis |
| `GEMINI_MODEL` | Server-side model override; defaults to `gemini-3.5-flash-lite` | No |

Never name the model key `VITE_GEMINI_API_KEY`: Vite exposes `VITE_` variables to browser code. Never use a Supabase service-role key in this app. `.env.example` contains placeholders only.

## Local development

The regular Vite command serves the frontend but does not execute Vercel functions:

```sh
npm run dev
```

To test `/api/demo-session` and `/api/analyze` locally, use Vercel's development server after signing in to the Vercel CLI and linking the project if prompted. The plain Vite server does not provide API routes:

```sh
npx vercel dev
```

Provide the environment values above in the ignored `.env.local` file or Vercel's server environment. Set the three Demo Access values to enable credential-based demo sign-in. Never commit real environment files.

## Supabase database migration

`supabase/migrations/202611230001_sentinel_foundation.sql` extends the existing PreScribe `profiles` table and adds SENTINEL consent and analysis tables. Apply and verify migrations for the intended Supabase project before using the database foundation. The current sign-in flow falls back to the auth user's display name if the SENTINEL profile migration or profile row is unavailable; the analysis demo history does not currently use the database tables.

## Vercel preparation

Vercel builds the Vite frontend with `npm run build` and automatically detects TypeScript functions in the root `/api` directory. `vercel.json` preserves the SPA fallback and assigns the analysis function a 30-second maximum duration. Set environment variables in the Vercel project before using the deployed analysis endpoint. Confirm the Supabase Site URL and allowed email redirect URLs match the hosted app.

To deploy later, link the repository to a Vercel project, add the environment variables, then deploy from the Vercel dashboard or with:

```sh
npx vercel --prod
```

No deployment is performed by this repository setup.

## Current scope and limitations

- Analysis accepts text only. The image picker remains visible, but images are not uploaded or sent to Gemini.
- Analysis history is stored locally in the browser, scoped by Supabase user ID, and limited to the newest 50 results. It does not sync across devices.
- Dashboard metrics, emotion distribution, recent results, and seven-day trends use saved real analyses when available. Otherwise, any displayed illustrative examples are labeled as sample data.
- Behavioral signals are text observations and must not be treated as diagnoses or proof of an ongoing state.
- Password recovery sends a Supabase recovery email; a dedicated password-update screen is not part of this phase.
- Existing PreScribe pages, services, and Edge Functions remain outside the active SENTINEL routes.
